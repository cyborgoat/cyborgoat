## Featured projects

Four apps I'm actively building and releasing. All are open source (MIT) and keep
your data on your own machine.

| Project | What it does | Built with |
| --- | --- | --- |
| 🪺 **[Nest](https://github.com/cyborgoat/nest)** | A local-first desktop knowledge workspace. Read and edit Markdown knowledge packs, and chat with them through retrieval-augmented generation using any OpenAI-compatible LLM. Includes an optional pack Hub. | Tauri v2, Rust, React, NestJS, SQLite FTS, FastEmbed |
| 🧩 **[Quizzy](https://github.com/cyborgoat/quizzy)** | A desktop quiz app that turns a folder of JSON files into a study tool, with study goals, attempt history, a mistake log, and linked Markdown notes. | Tauri v2, Rust, React, TypeScript |
| 🎙️ **[Finch](https://github.com/cyborgoat/finch)** | Local-first voice transcription with speaker labels, remembered voiceprints, and optional AI notes. Audio never leaves your machine. | Python, FastAPI, Qwen3-ASR, pyannote, TanStack Start |
| 🛰️ **[Team Orbit](https://github.com/cyborgoat/teamorbit)** | A self-hosted collaboration backend for small teams: members, events, news, a forum, and live notifications, with a typed TypeScript client. | NestJS, Prisma, SQLite, Socket.io, React |

## More projects

| Project | Description |
| --- | --- |
| **[Cubicles](https://github.com/cyborgoat/cubicles)** | An inspectable, tool-driven agent workbench: persistent sessions, traceable memory, and explicit tool approvals, with CLI and web interfaces. Works with Ollama and OpenAI-compatible providers. |
| **[Swarm](https://github.com/cyborgoat/swarm)** | A CLI agent for web browsing, automation, and deep research, exposing browser tools to LLMs over MCP. |
| **[Pronto](https://github.com/cyborgoat/pronto)** | A cross-platform desktop launcher for fast local search across apps, files, and folders. Tauri 2, Rust, React. |
| **[Omnichat](https://github.com/cyborgoat/omnichat)** | An all-in-one chat client for multiple LLM providers, on the web and desktop, with custom endpoints and reasoning-model support. |
| **[mdmailer](https://github.com/cyborgoat/mdmailer)** | Turn a Markdown file into a branded HTML/EML email. Published to npm as a CLI and a reusable core library. |
| **[skills-enhanced](https://github.com/cyborgoat/skills-enhanced)** | A collection of custom Claude skills, including a PowerPoint generator with a modern visual theme. |
| **[sub-converter](https://github.com/cyborgoat/sub-converter)** | Convert proxy subscriptions into compact Clash-compatible YAML with a Cloudflare Worker and a small web UI. |
