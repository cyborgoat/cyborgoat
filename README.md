# Junxiao Guo

I’m an AI developer and software engineer. I build software that saves people time in everyday life, and I write about what I learn while building it.

I lead an engineering team working on language models and AI agents. My work spans agent frameworks, model optimization, retrieval, and the backend systems that make these tools useful. I build desktop and web apps with Python, TypeScript, Java, and Rust, and work with databases including PostgreSQL and SQLite.
